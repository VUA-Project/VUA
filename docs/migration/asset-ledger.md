# Legacy asset migration ledger

> Status: Historical reference; no current implementation authority
> Updated: 2026-10-02

The original migration record from `VRC_Ultra_assistant` and `VUA_BDB` is preserved
[in the archive](../archive/2026-09-30/asset-ledger-original.md), including its original language,
commit references, historical test results and unavailable-screenshot note.

The migration extracted individual assets into new owners and contracts. It did not import entire
legacy branches or make the old repositories implementation dependencies. `VUA_BDB` was archived;
selected Orchestrator, Electron presentation and Unity Bridge assets were extracted or rebuilt.
Paid materials, user projects, credentials, raw logs and production databases were excluded.

These are historical decisions and evidence claims, not new test results or current acceptance.
Use the [documentation guide](../README.md) and [N sequence](../development-outline.md) for current work.
